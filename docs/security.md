# אבטחה ופרטיות

## גבולות אמון

הדפדפן והקלט ממנו אינם מהימנים. זיהוי משתמש אינו מוכיח הרשאה לעסק או
לרשומה. מפעיל המוצר אינו עובד של העסק ואינו מקבל גישה שגרתית לתוכן שלו.
ספק חיצוני ואירוע נכנס דורשים אימות, הרשאות מצומצמות וטיפול בכפילות.

| איום              | הגנה נדרשת                              | בדיקת קבלה                           |
| ----------------- | --------------------------------------- | ------------------------------------ |
| גישה לעסק אחר     | חברות מאומתת, RLS ומפתחות מורכבים       | קריאה/כתיבה/מחיקה וחיבורים ממוחזרים  |
| הרשאה גבוהה מדי   | תפקיד, היקף ורשומת יעד בשרת             | כל פעולה רגישה מול משתמש לא מורשה    |
| השתלטות על חשבון  | ספק מבוסס, אימות רב־שלבי וביטול חיבורים | קישור ישן, קוד חוזר והסרת עובד       |
| מסמך זדוני        | אחסון פרטי, סריקה ובדיקת תוכן           | קובץ מזויף, קישור שפג וגישה מעסק אחר |
| כפילות חיוב/הודעה | אימות חתימה ומפתח מניעת כפילות          | אירוע כפול, מאוחר ובסדר שונה         |
| דליפת סוד         | ניהול סודות וסינון יומנים               | סריקת מאגר ובדיקת תגובות שגיאה       |
| פגיעה בזמינות     | מכסות, עימוד, תורים והגבלת קצב          | עומס וצריכה חריגה של עסק אחד         |
| אובדן מידע        | גיבוי, שחזור ותוכנית תקלה               | שחזור נמדד בסביבה נפרדת              |

## מה כבר קיים

חשבון מסד מוגבל, RLS כפוי, הקשר מקומי לעסקה, שאילתות עם פרמטרים,
בדיקות בידוד מול מסד אמיתי, כותרות הגנה בשרת והגדרות פיתוח אקראיות
בקובץ מוחרג. אלו בסיס בלבד ולא מימוש מלא של הטבלה.

## לפני השקה

- הזדהות, חברות והרשאות; אימות רב־שלבי למנהלים ובעלים.
- מדיניות חיבורים, שחזור גישה, הגבלת קצב והגנת בקשות בהתאם לשיטת ההזדהות.
- הצפנה, סודות מנוהלים, הרשאות מינימליות וסריקת תלויות.
- יומן ביקורת, גישת תמיכה חריגה מוגבלת ומאושרת, ויכולת ביטול.
- יצוא ומחיקה שמכסים מסד, קבצים, תורים, חיפוש וגיבויים.
- תנאי שימוש, הסכם עיבוד מידע, מדיניות פרטיות ורשימת ספקי משנה בהתאם
  למדינות המכירה. אין כאן קביעה משפטית של עמידה בחוק.
- בדיקת חדירה, טיפול בממצאים קריטיים וגבוהים ונוהל תגובה לאירוע.

אין לשמור פרטי כרטיס במערכת. מידע רפואי או מידע רגיש במיוחד אינו נתמך
רשמית לפני בחינה נפרדת. שיתוף מידע עם ספק בינה מלאכותית יחייב מדיניות
והסכמה מתאימות לפני הפעלת היכולת.

## דיווח חולשה

אין לפרסם מידע אישי, סודות או הדגמת תקיפה על עסקים אמיתיים. לפני פתיחת
המוצר לציבור יוגדר ערוץ דיווח פרטי ואחראי לטיפול; כרגע אין כתובת מומצאת.
