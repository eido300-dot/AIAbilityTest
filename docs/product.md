# אפיון המוצר

מצב: קו בסיס שאושר בשיחה לצורך הכנת המאגר. שינויים מהותיים יתועדו כהחלטה.

## המטרה והקהל

שירות ענן לניהול לקוחות, מכירות ועבודה שוטפת, למכירה לעסקים קטנים ובינוניים.
אין התמחות בענף מסוים ואין כניסת לקוחות קצה. כל עסק מקבל סביבת עבודה נפרדת.
משתמש יכול להיות חבר בכמה עסקים; בחירת העסק הפעיל תמיד מפורשת.
המאגר ממשיך לשמש ניסוי מתועד באיכות פיתוח בעזרת בינה מלאכותית.

## מונחים ומודל

| מונח    | משמעות                               |
| ------- | ------------------------------------ |
| עסק     | הארגון המנוי למוצר; גבול הבידוד      |
| משתמש   | אדם מזוהה, עם חברות ותפקיד בכל עסק   |
| צוות    | קבוצת עובדים בתוך עסק                |
| לקוח    | חברה או אדם שהעסק מנהל               |
| איש קשר | אדם עם שיוך אחד או יותר לחברות       |
| פנייה   | התעניינות לפני סיווג והמרה           |
| הזדמנות | עסקה אפשרית, עם שלב, סכום ומטבע      |
| פעילות  | אירוע בציר הלקוח, כגון הערה או פגישה |

ישויות מתוכננות: משתמשים, חברויות, צוותים, לקוחות, אנשי קשר ושיוכים,
פניות, תהליכים ושלבים, הזדמנויות, משימות, פעילויות, מסמכים, הגדרות שדות,
אירועי ביקורת, חיבורים, מנויים ואירועי חיוב. רק עסקים ולקוחות קיימים כעת
בגרסת המסד הראשונה; זה אינו מודל עסקי שלם.

## היקף ההשקה

1. עסק, הזמנת עובדים, תפקידים, אימות רב־שלבי ומעבר בין עסקים.
2. לקוחות פרטיים וחברות, אנשי קשר, אחראי, צוות, תגיות וארכוב.
3. שדות מותאמים: טקסט, מספר, תאריך, בחירה ובחירה מרובה, וסימון כן/לא.
4. פניות: מקור, מצב, אחראי, זיהוי כפילויות והמרה אטומית.
5. מכירות: כמה תהליכים, שלבים מותאמים, תנאי מעבר וסיבות זכייה והפסד.
6. משימות, פגישות, חזרתיות, אזורי זמן, תזכורות וציר פעילות.
7. קבצים פרטיים, סריקה, הרשאות, מכסות וניקוי קבצים יתומים.
8. חיפוש, מסננים ותצוגות שמורות, ייבוא, יצוא ומיזוג מבוקר.
9. דוחות מכירות, המרה, משימות באיחור ופעילות צוותית.
10. חבילות, ניסיון של 14 יום ללא כרטיס, מנוי חודשי/שנתי ומכסות.
11. חיבורי דואר ויומן של גוגל ומיקרוסופט, והרשאות ביטול וסנכרון.
12. אוטומציות מוגדרות: הקצאת פנייה, תזכורת ומשימת המשך.

הרחבות מאוחרות: אזור לקוחות, מלאי, חשבונאות מלאה, מוקד שירות מתקדם,
מחולל אוטומציות חופשי, יישומון עצמאי, עבודה ללא חיבור ובינה מלאכותית.
וואטסאפ, טלפוניה, חתימות וחיבורי חשבונאות ייקבעו לפי ביקוש וספקים.

## כללים עסקיים

- שיוך בין רשומות לעולם אינו חוצה עסקים.
- טלפון ודואר מציעים כפילויות אך אינם ייחודיים אוטומטית.
- מיזוג כולל תצוגה מקדימה, הרשאה ושימור היסטוריה וקשרים.
- העברת אחריות וטיפול בעזיבת עובד לא משאירים רשומות בלי בעלות מוגדרת.
- שדות מותאמים מאומתים בשרת; שינוי סוג או מחיקה לא מאבדים מידע בשקט.
- מעבר שלב יכול לחייב שדות; סגירה בהפסד מחייבת סיבה.
- סכומים נשמרים בערך עשרוני מדויק ובמטבע מפורש. אין חיבור מטבעות שונים
  בלי שער המרה מתועד; בגרסה הראשונה דוחות מופרדים לפי מטבע.
- עריכה מקבילה מחייבת מניעת דריסה שקטה.
- ברירת המחדל להסרת לקוח מהעבודה היא ארכוב. למחיקה תקופת שחזור של 30 יום,
  בכפוף לבקשת מחיקה מחייבת ומדיניות הדין הרלוונטי.
- יצוא פרטי, זמני ומתועד. הרשאות נבדקות גם בעת הורדה.
- כשל בתשלום או חריגה מחבילה אינם מוחקים מידע; הגבלות מדורגות ותקופת חסד
  יוגדרו לפני חיבור חיוב חי.

## תפקידים והרשאות

| תפקיד     | היקף ברירת מחדל                           |
| --------- | ----------------------------------------- |
| בעל עסק   | כלל העסק, בעלות, מנוי וסגירת עסק          |
| מנהל עסקי | משתמשים, הגדרות ותהליכים; ללא העברת בעלות |
| מנהל צוות | נתוני צוות, הקצאה ודוחות צוות             |
| עובד      | נתונים אישיים ומשותפים בהתאם לשיתוף       |
| צופה      | צפייה בנתונים מורשים בלבד                 |

ליצוא, ייבוא, מיזוג, מחיקה ושינוי הרשאות יכולות נפרדות. פעולות מרוכזות
מכבדות הרשאת כל רשומה. הרשאות לשדות ותפקידים מותאמים הן הרחבה מתוכננת;
הערה פרטית, כשתמומש, חייבת להישאר פרטית גם בחיפוש, דוח ויצוא.
אימות רב־שלבי חובה לבעלים, למנהלים ולמפעילי המוצר.

## מסכים ועיצוב

עברית ואנגלית מההשקה; תמיכה מלאה בכיווניות, תאריכים ומטבעות. ממשק מותאם
למחשב ולנייד עם מסך בית, לקוחות, פניות, הזדמנויות, משימות, דוחות והגדרות.
כרטיס לקוח כולל פרטים, פעולה הבאה, ציר פעילות, אנשי קשר, עסקאות ומסמכים.
יש להציג מצבי טעינה, ריק, שגיאה ונתונים חלקיים. שגיאה לא מוחקת קלט.
נדרשות מקלדת, קורא מסך, ניגודיות וחלופה לפעולות גרירה.
יעד נגישות: WCAG 2.2 AA, עם בדיקות ידניות ואוטומטיות לפני השקה.
מסך הפיתוח הנוכחי בעברית בלבד; הוא אינו מימוש מסכי המוצר.

## יעדי תכנון, טרם הוכחה

| יעד      | ערך ותנאי                                                 |
| -------- | --------------------------------------------------------- |
| עסקים    | 100 בהיקף הבדיקה הראשוני                                  |
| משתמשים  | 2,000 רשומים, 200 פעילים במקביל בתמהיל שיוגדר             |
| מידע     | מיליון לקוחות ואנשי קשר במצטבר, כולל עסק גדול במיוחד      |
| שרת      | אחוזון 95 עד 500 אלפיות שנייה לפעולות רגילות בעומס המוסכם |
| מסך      | תוכן שימושי בתוך כשתי שניות בתנאי רשת ומכשיר מתועדים      |
| זמינות   | יעד 99.9% חודשי; מוכח רק במדידה תפעולית                   |
| התאוששות | עד ארבע שעות, אובדן מרבי של 15 דקות                       |

דוחות כבדים ופעולות גדולות ירוצו ברקע. המחירים, מדיניות החסד, מדינות המכירה
והספקים ייקבעו לפני מסחור. אחסון ראשוני באיחוד האירופי הוא ברירת תכנון,
ולא תשתית שכבר הוקמה. מידע רפואי או רגיש במיוחד מחייב בחינה נפרדת.
