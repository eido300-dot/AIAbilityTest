# עובד רקע — חוזה עתידי

אין כרגע תהליך עובד רקע או תור הודעות. הם יתווספו בשלב המשימות והאוטומציות;
אין להציג תיקייה זו כשירות עובד.

כל עבודה תכלול מזהה עסק ומזהה למניעת כפילות. לפני ביצוע וחשיפת תוצאה ייבדקו
הרשאות עדכניות. יוגדרו ניסיונות חוזרים מוגבלים, תור לכשלים, ביטול ותיעוד.
גישה לנתונים תשתמש בהקשר עסקי מקומי לעסקה כמו בשרת.
